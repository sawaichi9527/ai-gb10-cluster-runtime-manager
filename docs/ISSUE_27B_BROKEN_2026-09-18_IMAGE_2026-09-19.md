# 27B TP2 BROKEN on 2026-09-18 image — diagnosis & fix options

> 記錄日期：2026-09-19。狀態：**BROKEN（未修）**，README 已標註。本次 session 僅記錄方向，未做修改。

## 現象

`gb10 use 27b`（cluster TP2，image `ghcr.io/aeon-7/aeon-vllm-ultimate:2026-09-18-v0.29.0-omni`）兩節點皆 **fatal**：

```
ERROR 09-18 17:39:50 [__init__.py:72]     from vllm.entrypoints.serve.utils.error_response import create_error_response
ERROR 09-18 17:39:50 [__init__.py:72] ModuleNotFoundError: No module named 'vllm.entrypoints.serve.utils.error_response'
(EngineCore pid=283) ERROR ...
```

- node0 / node1（`10.0.101.102`）都掛，engine fatal exit，容器被 `gb10 stop` 移除。
- 同一 image 的 **35B 正常**（能 boot → READY → smoke OK），且 docker logs 也有**同一行 ERROR**（`No module named ... error_response`）但 **非致命**（fallback 繼續）。

## 觸發 commit

`2d44cd2`（cluster-profiles: upgrade both TP2 images to 09-18, drop 27b binds）：

- 27b：IMAGE → `2026-09-18-v0.29.0-omni`，並移除 3 個 baked binds（`modelopt`、`qwen3_dflash2`、`triton_attn`）—— 認為「新 image 已 baked in」。
- 35b：IMAGE → 同上；`flash_attn` bind（`flash_attn_029_patched.py`）保留。

## 27b 與 35b 的關鍵差異（此 image 下）

| | 35b（WORK） | 27b（BROKEN） |
|---|---|---|
| ATTN_BACKEND | `flash_attn` | `TRITON_ATTN` |
| SPEC_ATTN_BACKEND | `flash_attn` | `TRITON_ATTN` |
| patch bind | `flash_attn_029_patched.py`（保留） | 無（`2d44cd2` 移除） |
| EXTRA_ENV | — | `VLLM_USE_V2_MODEL_RUNNER=1`（V2 runner whitelists dflash2） |

`vllm.entrypoints.serve.utils.error_response` 在 09-18 image 的 vllm_omni 中 import 失敗。35b 走到非致命 fallback；27b（V2 runner / DFlash2 路徑）把同一 import 視為必需 → fatal。

## 修復方向（未測試，待驗證）

1. **(a) 27b 添加 attention bind 或其他 patch**：仿 35b 作法，讓 27b 的 V2/DFlash2 路徑使用新 image 的正確 shim。需先查 09-18 image 內 `vllm/entrypoints/serve/utils/error_response.py` 是否存在／已改名（若整體移除，可能是 vllm_omni 對 09-18 的已知 shim 缺口）。
2. **(b) 補 `error_response` 相容層**：讓 vllm_omni 的 import 不 fatal（upstream patch／該行 fallback）。適用於所有 profile。
3. **(c) 27b cluster profile 回退 09-11 image**（`2026-09-11-v0.29.0-omni`，此前 27b 正常）。決策已定：**維持 09-18**，此為 last resort。

## 評估後預設的下一步

- 先 `docker run --rm --entrypoint bash <09-18 image> -c 'ls /usr/local/lib/python3.12/site-packages/vllm/entrypoints/serve/utils/ | grep'` 確認 `error_response` 在 image 內是否仍存在。
- 若存在 → 27b fatal 是「該如何在 V2/DFlash2 路徑 import」的問題（也許 35b 的 flash_attn bind 恰好避免進入該 import），可比對兩者 engine 早期日志。
- 若不存在 → 走 (b) shim 或 (a) bind patch。
